# Support

Thank you for using projects maintained by **yggdevsec-labs**.

## Getting Help

For questions, bug reports, or problems using a project:

1. Check the project's `README.md` and existing GitHub Issues first.
2. Open an issue in the **relevant project's repository**, if Issues are enabled.
3. For general questions, use GitHub Discussions if the project has enabled them.

When reporting a problem, please include:

- The project name and version (or commit, if relevant).
- A brief description of the problem.
- Steps to reproduce it, including expected and actual behavior.
- Relevant error messages and environment details.

**Never include passwords, API keys, access tokens, or other sensitive information in public reports.**

## Feature Requests

Suggestions and feature requests are welcome through Issues in the relevant repository, when enabled. Please explain the use case and the improvement you are proposing.

## Reporting Security Vulnerabilities

**Do not report security vulnerabilities through public Issues or Discussions.**

Follow the [Security Policy](https://github.com/yggdevsec-labs/.github/blob/main/SECURITY.md). Use GitHub Private Vulnerability Reporting for the affected repository if available. Otherwise, report the issue privately to **dev@yggdevsec.com**.

## Support Availability

These projects are maintained on a best-effort basis. Response times and fixes are not guaranteed.

## Scope

This document provides default support guidance for public repositories maintained by **yggdevsec-labs**, unless a repository provides its own `SUPPORT.md`.
